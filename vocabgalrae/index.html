나의 목적에서 시작하는 단어 공부

현재 출시 준비 중입니다. 대한민국 App Store에 무료로 출시할 예정이며, 공개 일정은 아직 정해지지 않았습니다.

  • 직장·일상
  • 영어시험

뜻 익히기, 뜻 고르기, 철자 입력, 듣고 익히기, 문장 속 단어로 공부합니다. 의미별 복습과 개인 단어장으로 배운 내용을 이어 갑니다.

회원가입 없이 기본 학습·검색·기록을 기기에 보관합니다. 기본 코스와 학습 기능은 무료이며, 하루 목표를 채운 뒤에도 계속 공부할 수 있습니다. 광고는 오늘·단어장 탐색 화면에만 표시하고 문제 풀이와 학습 결과에는 표시하지 않습니다.

iPhone·iPad의 화면과 창 크기에 맞춰 구성하며, iOS·iPadOS 18 이상을 대상으로 준비하고 있습니다.

현재 준비한 콘텐츠: 고유 표제어 320개 · 다단어 표현 116개 · 의미와 예문 각 444개. 자체 작성·모델 검토 자료이며 사람 검수는 0건입니다. 시험 기관의 공식 어휘 목록이나 점수 보장을 의미하지 않습니다.

지원·문의

앱 이용이나 콘텐츠 오류는 lhyundong.kiml@gmail.com으로 알려 주세요.

앱 버전, 기기·OS 버전, 문제가 발생한 화면과 순서를 함께 적어 주시면 확인에 도움이 됩니다. 단어 오류는 단어·뜻·예문 또는 항목 ID를 알려 주세요.

학습 기록과 백업

설정의 백업과 복원에서 파일을 내보내고 다시 가져올 수 있습니다. 개인 단어장은 CSV 가져오기 전에 중복을 확인하며, 가져온 자료는 공용 콘텐츠에 자동으로 편입하지 않습니다.

오프라인 발음과 선택 동기화

발음은 기기에 설치된 영어 음성을 사용합니다. 네트워크가 없어도 기본 학습과 저장을 계속할 수 있으며, iCloud는 설정에서 선택할 수 있습니다. 동기화 상태와 마지막 성공 시점은 설정에서 확인합니다.

개인정보처리방침

영단어 갈래 개인정보처리방침
개정일: 2026년 11월 24일 · 1.0.1부터 적용
운영·문의: Hyun Dong Kim · lhyundong.kiml@gmail.com

1. 회원가입 없이 이용
학습 이벤트, 복습 일정, 즐겨찾기, 개인 단어장·메모, 설정과 진행 중 문항은 기본적으로 기기에 저장합니다. 운영자의 학습 데이터 수집 서버나 런타임 AI·번역 서비스로 전송하지 않습니다. 기기 백업 설정에 따라 Apple의 기기 백업에 포함될 수 있습니다.

2. 선택하는 iCloud 동기화
설정에서 켜면 학습 이벤트·즐겨찾기·개인 단어장·삭제 표시를 본인 Apple 계정의 CloudKit 비공개 데이터베이스에서 동기화합니다. 설정과 진행 중 문항은 이 기기에 유지합니다. 끄면 이후 동기화는 중지되나 이미 저장된 iCloud 데이터는 자동 삭제되지 않습니다. Apple 계정과 iCloud의 저장·보호 정책이 적용됩니다. 연결이 없어도 로컬 학습을 계속할 수 있습니다.

3. 광고와 동의
오늘·단어장 탐색 화면에서만 Google AdMob 배너를 사용합니다. 학습·문제·결과·기록·설정·온보딩 화면에는 광고가 없습니다. 1.0.1부터 생년월일이나 연령 구간을 묻지 않으며, 모든 사용자에게 전체 이용가(G등급) 광고만 요청합니다. 모든 광고 요청에는 Google의 아동 보호 처리를 적용하며 광고 식별자(IDFA) 전송과 개인 맞춤형 광고를 제한합니다. UMP에도 동의 연령 미만 보호 설정을 전달하며 광고 요청을 허용하는 조건에서만 요청합니다.
광고 추적을 최소화하기 위해 제한적 광고, 비개인화 요청, 게시자 개인화 및 게시자 자사 ID 비활성화를 적용하고 ATT 권한을 요청하지 않습니다. 제한적 광고도 데이터 수집이 전혀 없다는 의미는 아닙니다. Google SDK는 요청 시 IP 주소(대략적인 지역), 기기·앱 정보, 광고 관련 식별정보, 광고 표시·상호작용, 진단·성능 정보를 광고 제공·측정·보안·부정행위 방지 목적으로 처리할 수 있습니다. Google의 서버는 국외에 있을 수 있습니다. 개인 단어장 내용·학습 답안·이메일 주소를 광고 요청에 전달하지 않습니다.
기기 위치 권한을 요청하지 않으며 SDK의 자동 대략적 위치 수집도 비활성화합니다. IP 주소에서 추정되는 지역 정보까지 없어지는 것은 아닙니다. 실행 시 Google UMP 정보를 갱신합니다. 아동 보호 설정에서는 동의 화면이 생략될 수 있으며 Google이 요구하면 설정에 개인정보 선택 변경 메뉴를 제공합니다. 광고 수신이나 동의 여부에 관계없이 학습 기능은 동일하게 무료입니다.
이전 1.0.0에서는 기기에 저장된 연령 구간이 18세 이상일 때만 광고를 요청했습니다. 1.0.1에서는 이 값을 사용하거나 전송하지 않으며 학습 기록·개인 단어장은 유지합니다.
Google 안내: https://developers.google.com/admob/ios/privacy/data-disclosure
Google 개인정보처리방침: https://policies.google.com/privacy

4. 발음·알림·가져오기
발음은 기기 AVSpeechSynthesizer를 사용합니다. 설치된 음성에 따라 오프라인 재생이 가능합니다. 마이크 녹음은 하지 않습니다. 알림은 사용자가 허용했을 때 선택한 시간에 기기에서 예약합니다. 가져온 텍스트·CSV는 개인 학습 데이터이며 공용 콘텐츠에 자동 편입하지 않습니다. 공유·내보내기는 사용자가 선택한 앱·저장 위치에 파일을 전달하므로 해당 서비스의 정책이 적용됩니다.

5. 보관과 삭제
로컬 데이터는 앱을 사용하는 동안 보관됩니다. iCloud 동기화를 꺼도 기존 클라우드 데이터가 남고 다른 기기에서 다시 병합될 수 있습니다. 개인 항목을 삭제하면 동기화를 위한 삭제 표시가 유지됩니다. 앱 삭제는 기기 내 앱 데이터를 삭제하지만 내보낸 파일이나 iCloud 자료까지 지우지는 않습니다. iCloud 저장 공간에서 앱 데이터를 관리할 수 있습니다. 운영자에게 전달된 문의 이메일은 답변과 문제 해결에 필요한 기간 보관하며, 삭제 요청을 위 문의처로 보내실 수 있습니다.

6. 변경
데이터 흐름이 바뀌면 이 문서와 공개 개인정보처리방침을 함께 갱신합니다. 이 앱은 대한민국 App Store에서 배포하며 위치·언어를 기준으로 실행을 차단하지 않습니다.

이 지원 페이지의 호스팅은 GitHub Pages가 제공합니다. 접속 로그 등 호스팅 서비스의 처리에 대해서는 GitHub 개인정보처리방침을 참고해 주세요.
