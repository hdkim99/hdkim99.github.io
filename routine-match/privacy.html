기기에 저장하는 정보

회원가입 없이 사용합니다. 루틴 이름·단계·메모·반복 일정·실행 기록은 기기에 저장합니다. 해당 내용을 개발자 서버나 광고 타기팅 정보로 전달하지 않습니다. 위젯용 다음 일정은 앱 전용 공유 저장 공간에 보관합니다. 기기 간 자동 동기화는 제공하지 않습니다.

알림과 파일

알림을 설정할 때 권한을 요청합니다. 거부해도 핵심 기능을 사용할 수 있습니다. 파일 백업을 내보내면 사용자가 선택한 저장 위치에서 파일을 관리합니다. 백업은 별도 암호화하지 않으며 안전한 위치에 보관해 주세요.

광고와 개인정보 선택

Google Mobile Ads 13.13.0과 User Messaging Platform 3.1.0을 사용합니다. 제한적 광고, 맞춤 광고 비활성화, 게시자 자체 식별자 비활성화, SDK 충돌 보고 비활성화를 적용합니다. ATT나 IDFA API를 호출하지 않습니다. 실행 중 광고는 표시하지 않습니다.

18세 미만 또는 연령 구간 미선택이면 운영 광고를 요청하지 않습니다. 연령 구간은 이 앱의 기기에만 저장하며 생년월일을 요구하지 않습니다. 운영 광고 요청 전 UMP 정보를 갱신하고 필요한 지역에서 공식 양식을 제공합니다. 필요한 경우 설정의 광고 개인정보 선택 관리에서 선택을 변경할 수 있습니다.

Google 및 광고 파트너는 광고 전달·측정·보안·부정 이용 방지를 위해 IP 주소, 대략적인 위치, 기기·앱 정보, 광고 노출·상호작용, 성능·진단 정보와 관련 저장소를 처리할 수 있습니다. 계정의 프로그래매틱 제한적 광고 설정에 따라 무효 트래픽 감지용 쿠키나 로컬 저장소가 사용될 수 있습니다. 제한적 광고는 데이터 수집이 없다는 뜻이 아닙니다. 외부 서비스의 보관 기간과 국외 처리 범위는 아래 Google 정책을 따릅니다.

보관과 삭제

로컬 데이터는 사용자가 삭제할 때까지 보관합니다. 설정에서 모두 삭제하면 루틴·실행·기록과 관련 알림·실시간 현황을 정리합니다. 파일로 내보낸 사본은 해당 위치에서 별도 삭제해야 합니다. 광고 연령 선택은 데이터 삭제 시 초기화됩니다.

문의와 웹사이트

문의 메일은 사용자가 직접 전송합니다. 발신 주소와 직접 작성·첨부한 내용은 문의 처리에 사용하며 해결 후 불필요한 자료를 삭제합니다. 이 사이트는 GitHub Pages로 제공하며 접속 정보는 GitHub의 개인정보 정책에 따라 처리될 수 있습니다.
