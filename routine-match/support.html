알림이 들리지 않아요

기기 설정의 알림 허용, 집중 모드, 음량을 확인해 주세요. 설정에서 알림 다시 설정을 누르면 가까운 일정부터 예약합니다. 일반 알림의 소리와 표시는 시스템 설정의 영향을 받습니다.

앱을 다시 열었는데 시간이 지났어요

화면 잠금과 앱 종료는 일시정지가 아닙니다. 현재 단계는 자동 완료되지 않습니다. 완료하거나 현재 단계에 얼마나 더 필요한지 입력해 주세요.

백업과 복원

설정에서 파일 백업을 내보낼 수 있습니다. 실행을 종료한 뒤 복원 파일을 선택하고 합치기 또는 교체를 선택하세요. 교체 전에 기존 데이터를 백업해 주세요. 진행 중 실행과 광고 선택은 백업에서 가져오지 않습니다.

저장 데이터가 열리지 않아요

앱을 삭제하지 말고 설정에서 원본 데이터 파일을 보관한 뒤 문의해 주세요. 파일 내용과 민감한 루틴 기록은 요청 없이 보내지 않으셔도 됩니다.

문의에 필요한 정보

기기 모델, OS 버전, 앱 버전, 문제가 생긴 조작과 오류 문구를 알려 주세요. 비밀번호는 보내지 마세요.
