집의 기록과 iCloud

물건 정보, 메모, 관리 기록, 업체 연락처, 사진과 문서는 기본적으로 기기에 저장됩니다. 자체 회원가입과 개발자 운영 저장 서버는 없습니다. 기기 전용 모드는 앱의 CloudKit 동기화를 사용하지 않는다는 뜻이며 iOS 기기 백업을 끄지는 않습니다. iCloud 사용을 선택하면 Apple CloudKit에 자료를 저장합니다. 가족 공유는 선택한 집 전체를 대상으로 하며 초대한 iCloud 계정이 자료에 접근합니다. 초대 이메일은 참여자 확인을 위해 Apple에 전달됩니다.

사진·문서와 권한

사용자가 선택한 사진과 파일을 앱에 복사합니다. 위치·주소록·마이크 권한은 요청하지 않습니다. 알림은 사용자가 기능을 선택한 뒤 권한을 요청하며 설정에서 끌 수 있습니다. 사진은 필요한 기능에서 선택하거나 권한을 요청합니다. 집의 입력 내용은 광고 요청에 전달하지 않습니다.

광고와 데이터 처리

Google Mobile Ads SDK로 홈과 우리집 목록에 제한적 배너 광고를 제공할 수 있습니다. 맞춤 광고나 다른 앱·웹사이트에 걸친 추적은 사용하지 않으며 추적 허용을 요청하지 않습니다. 광고 안내를 처음 확인하기 전에는 광고 요청을 시작하지 않습니다. 안내 확인은 추적 동의가 아닙니다. 광고가 없거나 안내를 확인하지 않아도 모든 기능을 이용할 수 있습니다. Google과 광고 파트너는 광고 전달·측정·보안·부정 이용 방지를 위해 IP 주소, 기기·앱 정보, 광고 노출·상호작용 및 성능·진단 정보를 처리할 수 있습니다. IP 주소로 대략적인 위치를 추정할 수 있고 부정 이용 방지용 쿠키 또는 로컬 저장소가 사용될 수 있습니다. 광고 개인화와 게시자 자체 식별자는 비활성화하며 SDK 충돌 보고도 끕니다. 집 이름·메모·사진·연락처·검색어를 광고 타기팅 정보로 보내지 않습니다.

삭제·공유 종료·백업

휴지통은 복원을 위해 자료를 보관하며 자동으로 비우지 않습니다. 영구 삭제와 전환·업데이트 복구 사본 정리는 설정에서 별도로 실행합니다. iCloud의 삭제 내용은 네트워크와 Apple 동기화 상태에 따라 다른 기기에 반영됩니다. 공유 중단 전에 소유자의 기기에 보호 사본을 만들며 필요하면 이 사본도 별도로 삭제해야 합니다. 참여자가 공유에서 나가도 소유자 원본은 남습니다. 외부로 내보낸 사본은 회수할 수 없습니다. 백업은 앱 자체 암호화가 없는 ZIP 파일이며 앱 삭제 후에도 내보낸 위치에 남을 수 있습니다.

외부 서비스와 문의

iCloud 자료는 Apple의 서비스 정책에 따라 처리됩니다. Google의 광고 처리 및 보관 기간은 Google 정책에 따릅니다. 지원 메일을 보내면 발신 주소와 직접 작성·첨부한 내용이 문의 처리에 사용되며 요청 해결 후 불필요한 자료를 삭제합니다. 민감한 집 자료를 요청 없이 보내지 마세요. 이 웹사이트는 GitHub Pages로 제공되며 호스팅 과정의 접속 정보는 GitHub 개인정보 정책에 따릅니다.
