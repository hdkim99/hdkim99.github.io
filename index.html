Usage Pocket 지원

Usage Pocket은 iPhone에서 연결한 AI 서비스의 사용량을 확인하는 독립 앱입니다. 서비스 구독이나 API 이용권을 판매하지 않습니다.

문의하기

lhyundong.kiml@gmail.com으로 앱 버전, iOS 버전, 문제가 발생한 서비스와 상황을 알려주세요. 비밀번호, API 키, 쿠키 또는 로그인 토큰은 보내지 마세요. 화면을 첨부할 때는 개인정보를 가려 주세요.

연결과 새로고침

홈의 + 또는 설정의 서비스 연결에서 본인 계정을 연결합니다. Codex와 Claude는 공식 웹 로그인 후 사용량 확인을 누르고, OpenRouter는 사용 중인 키를 입력합니다. 메인에는 연결이 완료된 서비스만 표시됩니다. 앱을 열거나 아래로 당겨 최신 사용량을 조회하세요. 제공자가 내장 브라우저 접근을 차단하면 공식 웹사이트에서 로그인 상태를 확인해 주세요. 보안 확인을 우회하는 기능은 없습니다.

위젯이 갱신되지 않나요?

위젯은 마지막으로 저장된 값을 표시합니다. 먼저 앱에서 새로고침하고, 위젯 편집에서 연결한 서비스를 선택해 주세요. 갱신 시점은 iOS가 관리합니다.

연결 해제와 개인정보

설정에서 OpenRouter 연결을 해제하거나 서비스 상세 화면에서 구독 연결을 해제할 수 있습니다. 설정 → 데이터 및 개인정보에서 기록을 삭제하고 개인정보처리방침을 볼 수 있습니다. 광고 동의 선택이 필요한 경우 설정 → 광고 및 개인정보 → 광고 개인정보 설정에서 변경할 수 있습니다.

Usage Pocket support

Usage Pocket is an independent iPhone utility for viewing usage from connected AI services. It does not sell provider subscriptions or API access.

Contact

Email lhyundong.kiml@gmail.com with your app version, iOS version, affected service, and a description of the issue. Never send passwords, API keys, cookies, or session tokens. Redact personal information from screenshots.

Connect and refresh

Use + on the home screen or Connect a service in Settings. For Codex and Claude, sign in on the official website and select the usage verification action. For OpenRouter, enter the key you already use. Only successfully connected services appear on the home screen. Open the app or pull to refresh. If a provider blocks embedded-browser access, check its official website; the app does not bypass security checks.

Widgets

Widgets display the latest saved readings. Refresh in the app first and select a connected service in the widget configuration. iOS controls when widgets update.

Disconnect and privacy

Disconnect OpenRouter in Settings, or disconnect a subscription on its service detail screen. Open Settings → Data & privacy to delete history or read the privacy policy. Where available, use Settings → Advertising & privacy → Ad privacy choices to change consent.
